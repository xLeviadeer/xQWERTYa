ⓘ y shows how uses works

in default ⌄
    types y

in profile_1 ⌄
    when no modifier 
        - types ⸉r from profile_1⸉
        - `uses` shifts this key to use behavior from r in the current profile (profile 1)
    when shift
        - types ⸉y-shift⸉
        - `uses` does not go into effect for `shift` because it is defined

in profile_2 ⌄
    types r
        - `uses` shifts this key to use behavior from r in the current (profile 2)
        - profile 2 is not defined as a key-profile in r 
        - profile 2 inherits from default & hence r is typed
