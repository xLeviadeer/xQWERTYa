in default ⌄
    types ⸉e-default⸉

in profile_1 ⌄
    when no modifier or any non-shift modifier
        - types e
        - instead of inheriting the profile is set to `else` which uses the target as the typed key
    when shift
        - types ⸉e-shift⸉

in profile_2 ⌄
    when no modifier or any non-shift modifier
        - types ⸉e-default⸉
        - profile_2 inherits from default
        - default collapses to default & hence types ⸉e-default⸉
    when shift
        - types e
        - shift is set to `else` which uses the target as the typed key
